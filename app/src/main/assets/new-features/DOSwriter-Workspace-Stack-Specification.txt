DOSwriter Workspace Stack Specification
Purpose
Provide a fast, keyboard-oriented workspace system that allows users to instantly switch between independent writing environments without closing files or losing context.
A Workspace represents a complete writing session, including buffers, projects, editor state, and preferences.
The Workspace system is designed for distraction-free writing and optimized for e-ink devices.

** Workspace Model
DOSwriter supports up to 16 Workspaces.
Each Workspace is completely independent.
Each Workspace contains:
* Outline Manager project
* Buffers 1-8
* Scratchpad
* To-Do workspace
* Cursor positions
* Recently viewed references
* Editor state
* Preview state
* Workspace preferences
Switching Workspaces restores the complete writing environment.

** Buffer Independence
Each Workspace maintains an independent set of:
* Buffers
* Modified flags
* Cursor positions
* Undo history
* Redo history
No state is shared between Workspaces.

** Scratchpad Buffer
Each Workspace owns its own Scratchpad.Buffer (Alt-9)

** Favorites
Users may pin favorite Workspaces.
Pinned Workspaces remain at the top of the selector regardless of MRU order.

** Workspace Switching
Before switching:
* modified buffers are detected
* auto-save rules are applied
* save prompts appear when required
Workspace switching never discards unsaved work.

** Session Persistence
Workspace state is automatically saved when:
* switching Workspaces
* exiting DOSwriter
* background autosave
* device sleep
No manual session save is required.

** Workspace File

** Workspace Duplication
Users may duplicate a Workspace.
Useful for:
* branching a novel
* experimenting with revisions
* creating project variations
Duplicated Workspaces receive independent state.

** Workspace Archive
Inactive Workspaces may be archived.
Archived Workspaces:
* disappear from normal selection
* retain complete state
* may be restored later

** Workspace Import/Export
Users may export or import Workspace files.
Exports include:
* Workspace metadata
* Outline references
* session state
* preferences
Linked documents remain external unless optional packaging is implemented.

** Performance
Workspace switching should complete nearly instantly.
Only the active Workspace remains fully loaded.
Inactive Workspaces maintain lightweight session metadata until activated.

** Design Goals
* Instant context switching
* Keyboard-first operation
* Zero disruption to writing flow
* Minimal UI complexity
* Optimized for e-ink devices
* Independent writing environments
* Fully compatible with Outline Manager and Preview Mode
* Simple enough for casual users while scalable for power users
