** Using DOSwriter
: The core of the app is using the keyboard to control your editing experience. <b>Visual appeal</b> from colors, margins, font sizes, and screen brightness <b>can be instantly adjusted through keyboard shortcuts</b>. Editing, text navigation, and file handling functions are based on standard Linux\Windows conventions. 

: Important DOSwriter concepts are the <b>8 file buffers</b> (F1-F8 or ALT+1-ALT+8) and <b>1 Scratchpad buffer</b> (F9 or ALT-9). These are like browser tabs and swap instantly. CTRL-ALT-B displays the buffer sin a layout view. 

: Think of buffers 1-8 as chapters in a book. There is a second set of 8 To-Do buffers which creates a printable task list. Buffers, cursor locations, and settings are persistent after you close and reopen the app.

: A keyboard with F keys is ideal for using DOSwriter since the F keys provide instant buffer swapping. On some keyboards you may need to use a lock function on the keyboard for the F keys to work with DOSwriter. Arrow keys are required for the app to function. When a keyboard is not attached, a Virtual Keyboard is displayed.

: <b>Note : Android Clipboard Popup</b> On some Android devices it is hard to disable the system clipboard popup when text is copied. This can be disabled in Settings > Advanced Features > Hardware > Suppress System Clipboard.

** Buffers
: Text can be copied and pasted between buffers. Buffers 1-8 are for long text files. The Scratchpad has an adjustable character limit and can be wiped or logged with a keystroke. This is useful for short texts such as social media posts. All buffer settings and files are retained when the app reboots.

<b>SHOW BUFFER WORKSPACE :</b> Esc 
: Displays Layout View of Buffers 1-8. Use arrow keys to select and open a buffer 
: In Layout Mode press Esc to return to buffer

<b>SHOW BUFFER PICK LIST :</b> ALT + B
: Shows buffers 1-8, Select named buffers 1-8.

<b>CHANGE CURRENT BUFFER :</b> F1-F8 or ALT + 1-8
: Instant swap to buffers 1-8.

<b>CLEAR CURRENT BUFFER (Prompts for confirmation) :</b> CTRL + N 
<b>CLEAR ALL BUFFERS (Prompts for confirmation) :</b> CTRL + ALT + W 

<b>SPLIT BUFFER VIEW :</b> CTRL-ALT-LEFT/RIGHT ARROW
: Shares any buffer in a split-screen view with any other buffer. 

** ScratchPad Buffer
The Scratchpad Buffer is a temporary buffer useful for social media posts or short notes.

<b>Key Features of the Scratchpad:</b>

: Character Limited: Designed for short texts. Adjust the limit in SETTINGS>Scratchpad Buffer.

: Persistent: The text remains in the Scratchpad even if you switch buffers or close the app, until you explicitly "Flush" it.

: Auto-Logging: When you save/flush, it appends the text to a dedicated log file, useful for keeping a chronological record of daily notes.

<b>Scratchpad Buffer keyboard shortcuts :</b>

: <b>Open the Scratchpad buffer :</b> F9 or ALT + 9

: <b>Flush and Save :</b> CTRL+F9 or CTRL+9,
: Saves the Scratchpad content to a log file and clears the buffer  

: <b>Flush without Saving :</b>  Ctrl-Shift-F9 or CTRL+Shift+9
: Instantly wipes the Scratchpad without saving to a file

** File Browser
: The default Android file manager is awkward for a keyboard app like DOSwriter because it breaks the mental focus from the keyboard to hand gesture/scrolling.

: It also suffers from screen clutter and wasted screen space by showing low-info previews and folder icons. This is ok for scrolling but frustrating for a keyboard app.

: DOSwriter has a keyboard-centric File Browser with file preview that allows you to open/save text files and create subfolders using keyboard commands. 

: It relies on the user defining linked folders which are used by the app as the working file folders. This simplifies file management since it does not need to handle files across the entire device.

** Using the File Browser

: Set Default Browser in Settings>File Manager>File Browser to DOSwriter

: To set up the File Manager you must first link your working folder in Settings (ALT-S ) > File Manager>Link Working Folder.
: This sets up a root folder from where DOSwriter accesses files.

: <b>Note: Folder Activation</b> If you cannot save files after linking a folder, try creating a single subfolder inside it using the standard Android File Manager. This "activates" the directory for the system.

: Once your root folder is set up, the File operations (ALT-F) comands use the DOSwriter file manager.

: <b>File Browser :</b> CTRL+ALT+F or ALT-F>File Browser
: This menu allows you to walk the working folder and subfolders to open files, create/delete subfolders, or delete files.

: <b>File Save :</b> CTRL+S and <b>File Save As :</b> CTRL+SHIFT+S use the File Browser interface


** Text Editing and Navigation
: Text handling commands are similar to PC/laptop  key combinations such as CTRL-C/V/X (copy, paste, cut). The CTRL and ALT keys combined with arrow and alphanumeric keys accomplish text navigation and editing, such as for jumping words, sentences, and paragraphs. The keyboard workflow is intuitive and easy to learn.

: DOSwriter can navigate large text files by key commands or finger/trackball scrolling. Typewriter mode text entry and scrolling keeps focus on a user-defined point in the screen. Page Up and Page Down (CTRL+[ / CTRL+]) can be set to various lengths depending on font size and margin viewport.

: File Size Limits : DOSwriter handles text files up to 30K-60K but may slow down on extremely large files. 

: Word Wrap is automatic. Imported files may contain extra Newline characters. The Unwrap function will strip them out for cleaner word wrapping.

** Editing Workflow Tools : Bookmarks, Macros, Text Collapse
<b>Bookmarks</b>
: The Bookmarks tool allows you to tag lines in your text that you can jump back to (CTRL + K) and stores the bookmarks in a named list so you can easily select which line to jump to (ALT + K)

<b>Text Macros</b>
: You can define text macros (word strings) that you can paste anywhere in the buffer with a hotkey. Up to 8 macros are stored for selection. There are multiple possible macro lists.

: A macro list has a Context to provide different macros for various file types. The default context for text files is Text. A Markdown Context with Headings and other common Markdown directives is active when editing Markdown files. There is a Code context you can populate for coding syntax.

<b>Text Collapse</b>
: This is a powerful feature for managing large text files. When text is selected in the buffer, on Simple Text Collapse the selected text is collapsed (hidden) and a Plus icon is displayed. Putting the cursor on the Plus icon and pressing Enter will expand the text.

: Text sections can be collapsed on all occurrences of a user-defined string pattern. If your file is too large you will get a warning to use Simple Collapse.

** Editing Workflow Tools : Manuscript Preview
: This tool helps with the problem of visualizing large texts on small devices. 

: The Manuscript Previewer (Ctrl-Q) displays the buffer text in a scrollable publication view, in either Layout or Filmstrip mode. The display is similar to printed page with adjustable page layouts. 

: In Layout View the document is presented in 8 or 4 page grids. 

: Filmstrip View shows the buffer one page at a time for quick scrolling with arrow keys. Pressing Enter on a page display will drop you into that section of the text. 

: This provides a fast way to visualize your buffer content and navigate the buffer. The buffer can be compiled to PDF from the Previewer vis CTRL-P. 
  
** DOSwriter Features : Outline Manager
: DOSwriter has an Outline Manager which provides hierarchical organization of your writing section or chapters. 

: You populate it with links to Android or host PC text files, as well as Markdown and image files.

: It features live preview so when you scroll through your Outine it will show you the file contents.

: If you select a file in preview mode it will load into the current buffer for editing.

: You can save your Outline to a project file for later reloading.


**  DOSwriter Virtual Keyboard
: When a hardware keyboard is not attached, a fast virtual keyboard optimized for DOSwriter operation is displayed.

: Keyboard size and appearance can be saved.

: Each buffer can have its own keyboard config or set globally.

: Instant app Minimization, Share, Text Macro, Settings, Outline Manager, Predictive Text, and ToDo Mode  hotkeys.

: Refer to Help>Virtual Keyboard Map

**  DOSwriter PDA, the Printable ToDo List

: A single Virtual Keyboard hotkey puts DOSwriter in ToDo Mode. This is useful on the go. In fact, it's transformative.

: With a Bluetooth keyboard, ALT-P enter ToDo Mode. DOSwriter instantly swaps your current 8 buffers for a secondary "To-Do" stack of 8 buffers. Both workspaces are saved independently, so your writing projects and task lists remain separate but equally accessible.

: The installation APK file has a pre-populated ToDo list. Modify and save for your own use.

: Your modified ToDo list can be printed out for total lifestyle management. Fold it on the lines and it becomes a pocket mini-book.

: A text buffer can be split-view with a buffer containing a PDF for note taking.

: Favorites can be set in the PDF file for jumping to quickly in a large file.

: The Favorites list can be exported to a text file.

: PDF navigation uses different keyboard shortcuts because it is not editing the file.


## PDF Mode Navigation
: <b>PREVIOUS / NEXT PAGE :</b> LEFT / RIGHT Arrow (or N / P)

: <b>FIRST / LAST PAGE :</b> ALT + UP / DOWN Arrow

: <b>GO TO PAGE :</b> CTRL + G

: <b>FAST VERTICAL PAN :</b> CTRL + UP / DOWN Arrow

: <b>HORIZONTAL PAN :</b> CTRL + LEFT / RIGHT Arrow

: <b>SNAP TO PAGE EDGE :</b> ALT + LEFT / RIGHT Arrow

: <b>ZOOM IN / OUT :</b> CTRL + PLUS (+) / CTRL + MINUS (-)

: <b>RESET PDF VIEW :</b> CTRL + R (Page 1, 100% Zoom)

: <b>ADD PAGE FAVORITE :</b> ALT-K

: <b>OPEN FAVORITES :</b> CTRL + K

: <b>EXPORT FAVORITES :</b> CTRL + ALT + P

: <b>FAVORITES LIST SIZE :</b> Settings → Text Display (8, 16, 32, or 64)

## Markdown Mode Features
Markdown Mode is automatically activated for any buffer with a .md file extension.

Markdown Mode supports :

: High-quality rendering of Headers (H1, H2), Bold, Italics, Strikethrough, Blockquotes, and Horizontal Rules.

: Dynamic Grids (Tables): Automatically detects standard Markdown table syntax (| cell |). Renders them as formatted grids with shaded headers and high-contrast borders.

: Inline Multimedia: Displays images using alt-path (see markdown-example.md). Supports relative paths in assets (e.g., images/diagram.png) and scales images responsively to the viewport width.

## How to use Markdown Mode 
<b>Markdown Editing</b>

: Name (or import with CTRL-O) your file with a .md extension.
: Edit the file using standard Markdown syntax.
: Render it Markdown ALT-R.
: Press Esc to return to edit mode.

<b>For Live Markdown Preview :</b>

: Name (or import with CTRL-O) your file with a .md extension.
: Use ALT-S to open the split preview.
: Write using standard Markdown syntax in left panel
: Use Macros (CTRL-M) to paste common Markdown directives
: Observe rendered Markdown in right panel

## Simple Text  Collapse
There are two text collapse functions, Simple and String Pattern.

When text is selected in the buffer, on Simple Text Collapse the selected text is collapsed (hidden) and a Plus icon is displayed. Placing the cursor on the Plus icon and pressing Enter will expand the text.

: <b>SIMPLE TEXT COLLAPSE</b> : CTRL + J,  collapse selected text
: <b>RECOLLAPSE LAST</b> : CTRL + SHIFT + J, recollapse last expanded text

Text sections can be collapsed on all occurrences of a user-defined string pattern. If your file is too large you will get a warning to use Simple Collapse.

: <b>COLLAPSE STRING PATTERN MANAGER</b> : ALT + J
: Opens a scrolling list containing up to 8 active patterns.
: Collapse All/Expand All options

: <b>DEFINE STRING PATTERN</b> : CTRL + ALT + J
: Opens a prompt to enter a custom text string which when inserted into the buffer text will collapse all text below it. 

String Pattern Collapse is more powerful by collapsing buffer text on occurrences of a user-defined text pattern. For all occurrences of the pattern the text is collapsed with a Plus icon. Multiple string patterns can be defined and saved.

String Pattern Collapse does not work for very large text files due to the overhead of managing collapsed text and icons. If your file is too large you will get a warning to use Simple Collapse.


## Paragraph Unwrap (Word Wrap)
The "Unwrap Paragraphs" function will strip out extraneous newlines from imported text files.

Load CTRL-E>Examples>word-wrap-example.txt into a buffer to see how this works. The file contains unwrap instructions.

This is how editors such as Emacs, BBEdit, and many ebook tools unwrap hard-wrapped text. It preserves paragraph breaks automatically and is much more reliable than regex replacements because it doesn't depend on the exact line-ending format.

To see the newline characters, turn on Newline visibility in Ctrl-L Setting>Text Display>CRLF Display.

Newlines can be removed with CTRL-ALT-U (Unwrap Paragraphs)

Or CTRL-L Setting>Text Display>Unwrap Paragraphs.

## Workspaces (Main vs. To-Do)
DOSwriter features two independent "stacks" of buffers. 

: **Main Mode**: Your primary workspace for writing projects.

: **To-Do Mode**: A secondary workspace containing 8 task-oriented buffers (e.g., Financial, Security, Shopping), which can be exported to a PDF for printing as a minialist PDA.

: Toggle between modes using **Alt + P** or the **TD** key on the virtual numeric keyboard. Both stacks are saved persistently.

## Virtual Keyboard

DOSwriter has a built-in virtual keyboard that activates when no physical keyboard is detected.

Refer to Help>Virtual Keyboard Map for detailed diagrams. 

The Virtual keyboard has 3 layers :
    Alpha - the ealpha keys and top number row "ABC"
    Punc - the punctuation characters and system hotkeys
    Num - numeric keyboard, Predictive Text and ToDo mode hotkeys

The keyboard uses the buffer color theme. In some cases turning on the outline improves visual clarity. Use SETTINGS>Virtual Keyboard>Keyboard Outlines.

The current keyboard configuration can be saved in SETTINGS>Virtual Keyboard.

Predictive Text can be turned on via the hotkey on the NUM keyboard layer.
