



### File
- `SAVE` or `CTRL-S`: Save current buffer to file.
- `CTRL-SHIFT-S`: Save As (opens system dialog).
- `CTRL-O`: Open File (opens system dialog).
- `CTRL-SHIFT-O`: Open Recent Files menu.
- `CTRL-W`: Close File / Clear Buffer.
- `CTRL-P`: Open PDF Export menu.
- `CTRL-Q`: Open Manuscript Filmstrip viewer.
- `CTRL-I`: Take Screenshot.
- `ESC`: Cancel current overlay or menu.
- `EXIT_SPLIT`: Close split-screen or exit active mode.

### Editing & Formatting
- `UNDO` or `CTRL-Z`: Undo last action.
- `REDO` or `CTRL-ALT-Z`: Redo last action.
- `COPY` or `CTRL-C`: Copy selection to internal clipboard.
- `CUT` or `CTRL-X`: Cut selection.
- `PASTE` or `CTRL-V`: Paste from clipboard.
- `SELECT_ALL` or `CTRL-A`: Select all text in buffer.
- `CTRL-F`: Open Find overlay.
- `CTRL-R`: Open Replace overlay.
- `CTRL-ALT-F`: Start Find Cursor (visual highlight).



### View
- `CTRL-B`: Move to the next buffer.
- `CTRL-ALT-B`: Move to the previous buffer.
- `ALT-B`: Open Buffer Selection menu.
- `ALT-N`: Swap focus between split-screen panels.
- `ALT-C`: Center view on cursor (triggers locator blink).
- `ALT-D`: Start/Stop Typewriter Demo.

### Settings
- `ALT-S`: Open Split-Screen orientation menu.
- `ALT-T`: Toggle Typewriter Mode.
- `CTRL-F11`: Recenter platen in Typewriter Mode.
- `ALT-R`: Toggle Markdown Rendering.
- `ALT-J`: Recollapse last fold expansion (8-level stack).
- `CTRL-J`: Open Pattern Collapse Manager.
- `CTRL-SHIFT-J`: Collapse all paragraphs in buffer.
- `CTRL-ALT-J`: Define new Pattern Collapse.
- `CTRL-M`: Fast Insert Macro picker.
- `CTRL-SHIFT-M`: Paste last used macro.
- `CTRL-ALT-M`: Open full Macro Manager.
- `ALT-K`: Toggle Virtual Keyboard.
- `ALT-M`: Toggle Margins visibility.
- `ALT-H`: Toggle Status Bar.
- `CTRL-H`: Open Help Menu.
- `CTRL-L`: Open Settings Master Menu.
- `ALT-L`: Open Line Spacing menu.
